# マップ管理ガイド (Map Management Guide)

このドキュメントでは、F1TENTH プロジェクトにおける地図の統合や管理方法について説明します。

## 🗺️ マップの統合 (Map Merging)

`teleop_map_manager.py` を使用して複数の地図セグメント（map_1, map_2...）を保存した場合、それらを1つの大きな地図に統合することができます。

> [!NOTE]
> 現在の設定では、マップを保存しても SLAM はリセットされません。これにより、同じ座標系を維持したまま複数のスナップショットを保存でき、精度の高い統合が可能です。

### 1. 統合スクリプトの使用方法

作成済みの `scripts/merge_maps.py` を使用します。

```bash
# 基本的な使い方
python3 scripts/merge_maps.py maps/<セッションディレクトリ名>

# 使用例
python3 scripts/merge_maps.py maps/session_0417_170334
```

### 2. スクリプトの動作仕様

- **位置合わせ:** 各地図のセグメントに紐付いている `.yaml` ファイルの `origin` (原点) 情報を読み取り、世界座標系上の正しい位置にピクセルを配置します。
- **ピクセル合成ルール:**
  - `障害物 (黒)` > `空きスペース (白)` > `未知 (灰色)` の優先順位で上書きします。
  - これにより、複数の地図で重複してスキャンされた箇所でも、障害物情報が正しく保持されます。
- **出力:** 指定したディレクトリ内に `merged_map.pgm` と `merged_map.yaml` が生成されます。

### 3. 注意点

> [!TIP]
> **座標系の継続:** 現在、マップ保存時に SLAM プロセスを終了しないように修正されています。そのため、1回のセッション内で複数回保存（1, 2, 3...）を行えば、それらの地図は完全に同じ座標系を共有します。これにより、`merge_maps.py` を使った際のズレが発生しなくなります。

## 🧹 マップの補正 (Map Refinement)

統合した直後の地図や、一度の走行で作成した地図には、ノイズ（浮遊する点）や壁の隙間が含まれることがあります。これらを自動でクリーンアップするために `scripts/refine_map.py` を使用します。

### 1. 補正スクリプトの使用方法

```bash
# 統合済みマップを補正する場合
python3 scripts/refine_map.py maps/session_XXXX/merged_map.yaml
```

### 2. 主な補正内容

- **ノイズ除去:** 孤立した小さな障害物（黒点）を除去します。
- **壁の整形:** 壁の微小な隙間を埋め、連続性を高めます。
- **自動トリミング:** 周囲の「未知領域（灰色）」を自動でカットし、マップサイズを最小化します。
  - **重要:** トリミングと同時に原点座標（Origin）を再計算するため、マップとしての位置整合性は保たれます。

### 3. 手動での修正 (GIMP等)

もし自動補正で満足できない場合は、`.pgm` ファイルを画像編集ソフトで直接修正できます。
- **注意点:** 
  - 保存形式は **グレースケール PGM** である必要があります。
  - 自由空間、障害物、未知領域の階調値（0, 254, 205）を変えないように注意してください。
  - 画像サイズを変更した場合は、対応する `.yaml` の `origin` や画像サイズを手動で修正する必要があります（困難なため、サイズ変更は `refine_map.py` に任せるのが無難です）。

## 📂 ディレクトリ構成

保存されたマップは以下のような構造で管理されます。

```text
maps/
└── session_MMDD_HHMMSS/       # 走行セッションごとのフォルダ
    ├── map_1_.../             # セグメント1
    ├── map_2_.../             # セグメント2
    ├── merged_map.pgm         # 統合後の画像
    └── merged_map.yaml        # 統合後のメタデータ
```

## 🛠️ マップの活用方法

統合したマップをプロジェクト全体で利用するには、プロジェクトルートの `maps/` 直下にコピーして名前を固定すると便利です。

```bash
cp maps/session_0417_170334/merged_map.yaml maps/course_full.yaml
cp maps/session_0417_170334/merged_map.pgm maps/course_full.pgm
```
