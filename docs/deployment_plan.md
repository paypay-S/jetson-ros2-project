# Jetson 実機デプロイ・最適化計画 (最新版)

Jetsonでの強化学習（PPO）モデルの推論や、ハードウェア制御、運用に関する今後の改善点とロードマップをまとめたドキュメントです。
本ドキュメントは、ONNX Runtimeの導入・各種フィルタリング（EMA等）・ヘッドレスSSH運用といった「初期対応」が完了したことを受け、より堅牢で高度な自律走行を目指すための課題と展望へと更新されています。

---

## 🚨 1. 潜在的な問題点（優先度：高）
現在のシステムで致命的なエラー（クラッシュ）に繋がり得る懸念点と、その対策です。

| 課題内容 | 起こり得る問題とリスク | 対策案・アクション |
| :--- | :--- | :--- |
| **ハードウェア・ウォッチドッグの欠如** | 推論ノードやROSシステムがクラッシュした際、`hardware_bridge` 側が直前のPWM値（前進など）を維持し続け、フルスピードで壁に激突する暴走リスクがあります。 | ハードウェアノード側に、一定時間（例: 0.2秒間）通信がないと強制的にニュートラルPWM（ESC=`esc_stop`）に戻す「デッドマン・スイッチ（タイムアウト）」機能を実装する。 |
| **LiDAR異常値への耐性不足** | 推論前のフィルタで対応しているものの、センサーが極端な異常値( `0.0` や `NaN`) を連続して出した際、AEB（緊急停止）が過剰反応して勝手に止まってしまう可能性があります。 | 単なるメディアンフィルタに加え、0.0（近接ノイズ）を `range_max` 側に寄せるか、外れ値を除去するクラスタリングの導入を検討する。 |

---

## 🛠️ 2. やっておいた方が良い改善（推奨タスク）
開発サイクルの効率（DX）や、チューニング体験を向上させるための運用改善タスクです。

- [ ] **モデルと正規化パラメータ（JSON）の自動プルスクリプト作成**
  - 現状はマップだけ `save_map.sh` で手動同期していますが、逆にトレーニング終了後の `models/*.onnx` と `*.json` を `f1tenth-rl-project` 側から自動で PULL（または SCP）してくる `sync_models.sh` などを導入することで、現場でのテストの回転数が飛躍的に上がります。
- [ ] **動的ROSパラメータ（Dynamic Reconfigure）の導入**
  - `speed_smoothing` や最大ハンドル切れ角などの微調整を、再起動なしで Foxglove Studio 等から走行中にリアルタイムに変更できるようにする。
- [ ] **ヘルスモニタ（Diagnostics）用ノードの実装**
  - AI推論ループのFPS、LiDAR測定周波数（Hz）、JetsonのCPU/GPU温度などをROSメッセージとして出力し、Foxgloveで可視化する。高負荷時のクロックダウン対策に繋がる。

## 🚀 3. 今後の展望・ロードマップ（発展タスク）
完全な自動化と、より上位の自律走行システムを実現するためのフェーズ構想です。

### フェーズ 1: 完全な Edge AI 最適化 (TensorRT)
現在の ONNX Runtime でも十分な速度が出ていますが、Jetson 環境における最適解は **TensorRT** です。
推論エンジンを `onnxruntime` から C++版 TensorRT や `torch2trt` に移行できれば、推論レイテンシを理論上 1/3 以下に削減でき、超高速走行時の急カーブにも対応可能な「超低遅延制御の極地」に到達できます。

### フェーズ 2: センサーフュージョン (VSLAM / VIO の導入)
2D LiDAR (108次元スキャン) に依存した強化学習は、特徴が少ない長い直線や対称なコーナーで「自分がどこにいるか」を見失う（自己位置推定のブレ）制約があります。
RealSense 等の深度またはステレオカメラを追加し、「視覚情報（VIO）」と融合させることで、推論の精度やマッピング性能が桁違いに向上し、より高次元な RLタスク（動的障害物回避など）が可能になります。

### フェーズ 3: 継続的学習 / Edge MLOps フローの確立
Jetson実機で走行した際に**「うまく走れなかったとき（AEB作動時、介入時など）」の LiDAR/コマンドデータを rosbag 等で自動保存**する機能を組み込みます。
このフィードバックデータを学習器に逆流させ、「失敗から継続的に学ぶ（Failure-based DAgger、オフライン強化学習の導入）」ループを作ることが、完全自動化（L4相当のRC自律走行）の最終目標となります。
